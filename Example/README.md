# UIAlertFlow Example App

UIKit example that loads **Main.storyboard**, imports the local **UIAlertFlow** package, and presents a sample sheet from a button.

## Open in Xcode

1. Open `Example/UIAlertFlowExample.xcodeproj`.
2. Select the **UIAlertFlowExample** scheme and an iOS 17+ simulator.
3. Press **Run** (⌘R).
4. Tap **Show sheet** to present the sheet.

## Package dependency

The app links to the parent package via **File → Add Package Dependencies → Add Local** (already configured as `relativePath = ..` in the project).
